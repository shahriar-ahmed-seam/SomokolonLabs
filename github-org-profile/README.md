# Somokolon Labs

AI & software development studio in Dhaka, Bangladesh — building LLM systems, applied ML, and
production software.

## What we build

- **AI & LLM systems** — multi-agent orchestration, retrieval pipelines, and LLM-backed
  application layers.
- **Applied ML** — model training and inference for audio, vision, and structured data,
  including on-device deployment.
- **Developer infrastructure** — vector search engines, event-driven serving platforms, and the
  tooling around them.
- **Business software** — full-stack web applications for real operational workflows.

## Focus areas

- AI & LLM engineering
- Web & full-stack development
- Cloud & MLOps
- Quality assurance & system design

## Flagship projects

| Project | What it is | Stack | Status |
| --- | --- | --- | --- |
| Nexus Agent Orchestrator | Autonomous multi-agent research and coding platform | LangGraph, FastAPI, Next.js, pgvector | In development |
| OrionStream ML | Event-driven ML inference platform | Kubernetes, Kafka, FastAPI, Prometheus | Prototype |

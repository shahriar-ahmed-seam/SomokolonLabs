# Security Policy

## Reporting a vulnerability

Email **security@somokolonlabs.com** with:

- a description of the issue and its impact,
- steps to reproduce (or a proof of concept),
- affected URL, route, or commit.

Please report privately rather than opening a public issue, and do not run tests that degrade the
service or access data belonging to others.

## Response expectation

- Acknowledgement within 3 business days.
- An initial assessment and planned next steps within 7 business days.
- Updates until the issue is resolved, and credit in the fix notes if you would like it.

## Supported versions

This repository holds a continuously deployed website; there are no released versions to
maintain. Only the current `main` branch, as deployed to somokolonlabs.com, receives security
fixes.
